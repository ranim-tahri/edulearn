JavaScript : rendre la page vivante

    Introduction à JavaScript

    JavaScript est le langage de programmation du web : il rend les pages interactives. On l'intègre avec <script src="script.js"></script>, de préférence en fin de <body>.

    On affiche un résultat dans la console du navigateur (touche F12) avec console.log().

    console.log("Bonjour le monde !");

    Variables et types

    On déclare une variable avec let (valeur modifiable) ou const (valeur constante). Les principaux types sont : nombre, chaîne de caractères, booléen, tableau et objet.

    On évite var, une ancienne syntaxe source d'erreurs.

    const prenom = "Sara";
let age = 20;
const langages = ["HTML", "CSS", "JS"];
age = age + 1;
console.log(`${prenom} a ${age} ans`);

    À retenir : Utilisez const par défaut, et let seulement si la valeur doit changer.

    Fonctions et conditions

    Une fonction regroupe du code réutilisable. Les conditions if / else permettent de choisir quoi exécuter. Les fonctions fléchées (=>) offrent une écriture courte.

    Les boucles (for, forEach) répètent une action pour chaque élément d'un tableau.

    const estMajeur = (age) => age >= 18;

if (estMajeur(20)) {
  console.log("Accès autorisé");
} else {
  console.log("Accès refusé");
}

["HTML", "CSS", "JS"].forEach((l) => console.log(l));

    Le DOM et les événements

    Le DOM est la représentation de la page en arbre d'éléments. On sélectionne un élément avec document.querySelector() et on réagit à une action de l'utilisateur avec addEventListener().

    C'est exactement ce que fait le menu burger et la barre de progression de ce site.

    const bouton = document.querySelector("#mon-bouton");
const titre = document.querySelector("h1");

bouton.addEventListener("click", () => {
  titre.textContent = "Vous avez cliqué !";
  titre.classList.toggle("actif");
});

    À retenir : Cette page utilise localStorage pour mémoriser votre progression dans le navigateur.
