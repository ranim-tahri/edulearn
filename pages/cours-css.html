    Introduction à CSS3

    CSS (Cascading Style Sheets) décrit l'apparence d'une page : couleurs, polices, marges, positionnement. On le sépare du HTML dans un fichier style.css relié avec <link rel="stylesheet">.

    Une règle CSS est composée d'un sélecteur et d'un bloc de déclarations propriété: valeur;.

    h1 {
  color: #4f46e5;
  font-size: 2rem;
}

.carte {
  padding: 20px;
  border-radius: 12px;
}

    À retenir : Les sélecteurs courants : balise (p), classe (.carte) et identifiant (#menu).

    Le modèle de boîte

    Chaque élément HTML est une boîte composée du contenu, du padding (espace intérieur), de la border (bordure) et de la margin (espace extérieur).

    Ajoutez box-sizing: border-box pour que la largeur inclue le padding et la bordure : c'est beaucoup plus simple à calculer.

    *, *::before, *::after {
  box-sizing: border-box;
}

.boite {
  width: 300px;
  padding: 16px;
  border: 2px solid #4f46e5;
  margin: 20px auto;
}

    Flexbox et Grid

    display: flex aligne les éléments sur une ligne ou une colonne. C'est idéal pour un menu ou une rangée de cartes. display: grid organise le contenu en lignes et colonnes : parfait pour une page entière.

    Avec Grid, grid-template-columns: repeat(3, 1fr) crée trois colonnes de même largeur.

    nav ul {
  display: flex;
  justify-content: space-around;
}

.grille {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

    À retenir : Flexbox = une dimension. Grid = deux dimensions.

    Responsive design et media queries

    Le responsive design adapte la page à la taille de l'écran. Il faut d'abord ajouter dans le <head> la balise <meta name="viewport" content="width=device-width, initial-scale=1.0">.

    Ensuite, les media queries appliquent des styles selon la largeur. L'approche « mobile-first » consiste à écrire le style mobile d'abord, puis à l'enrichir avec min-width.

    .grille { display: grid; grid-template-columns: 1fr; gap: 20px; }

@media (min-width: 768px) {
  .grille { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1024px) {
  .grille { grid-template-columns: repeat(3, 1fr); }
}
